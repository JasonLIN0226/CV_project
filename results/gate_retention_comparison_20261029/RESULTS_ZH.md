# Gate 保留策略：匹配评分器验证结果

这是原有 **192 个验证 episodes（96 对场景）** 的描述性结果，汇总了三个模型种子和两个预测时距；每个策略 1,152 行是同一批场景在不同种子和时距下的重复评估，不是 1,152 个独立场景。没有生成或访问新的独立测试集，原 Gate 评测不作为这次对比的筛选条件。

| 方法 | 路线/状态预测准确率 | 最终保留帧命中 cue 的比例 | 标准化 latent MSE（越低越好） |
|---|---:|---:|---:|
| 手动关键帧参考（使用 cue 信息） | 95.57% | 100.00% | 0.09783 |
| 删除代价监督的新评分器 | 94.53% | 100.00% | 0.09934 |
| Visual diversity | 71.79% | 47.40% | 0.11385 |
| Prediction surprise | 66.15% | 34.55% | 0.11765 |
| Reservoir | 57.38% | 16.84% | 0.12362 |
| Temporal buckets | 56.60% | 15.62% | 0.12256 |
| FIFO | 56.51% | 13.54% | 0.12423 |
| 特征相似度 attention proxy 监督的新评分器 | 56.08% | 13.72% | 0.12332 |
| 仅近期帧参考 | 50.00% | 0.00% | 0.12497 |

两个新评分器采用同一架构、相同参数量、训练样本、初始化与更新预算；其监督信号不同。删除代价教师使用冻结预测器和离线未来目标，可能天然与该预测器的评估对齐；特征相似度 proxy 使用未来特征相似性，它不是论文中通用 Transformer attention 的完整复现。两者教师计算成本不相同，不能把本结果解释为完全相同的总计算预算。手动参考拥有 cue 特权信息。

独立核验覆盖 4,608 条在线策略轨迹和 115,200 次状态转换，未发现已淘汰帧复活。此结果核验的是逻辑保留规则；离线重放仍保存完整历史前缀，不能据此宣称已经测得真实 B=2 物理内存开销。验证集结果也不能证明在新场景上同样成立，更不能作为新的 Phase 1 通过结论。
