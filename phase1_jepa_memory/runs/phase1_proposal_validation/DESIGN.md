# Proposal Phase1 下一轮验证

本轮只处理原Proposal的Gate与遮挡运动，目标是建立可靠使用关键历史的JEPA预测器。旧失败、指标、样本、训练种子与难例均保留；不复现FAR，不训练记忆保留策略，不打开封存确认集。

## 已有证据与工作假设

历史门状态/两帧运动方向可从原冻结JEPA特征读出，近期对照为机会水平。已有预测器在部分普通条件中有明显收益，但难背景、长延迟和部分种子仍失败。Gate的冻结成对诊断显示，历史预测的公共部分误差可能遮盖有效分支信息；该诊断依赖sibling，不能部署，也不保证任何训练修复有效。

固定候选采用“冻结近期预测 + 历史修正”。主分支复用每任务/种子的v3 reference，永远只接收合法近期画面/动作且权重冻结。侧分支是小型时间Transformer，全量读取当前合法保留集合。输出头零初始化；同一侧分支分别计算带历史与仅近期的系数，取差后加回近期基线。因此刚开始完全等同于旧近期预测，并且空历史在整个训练中始终等同于旧近期基线。

借鉴来源

- [Side-Tuning](https://arxiv.org/abs/1912.13503)，[官方代码](https://github.com/jozhang97/side-tuning)：冻结既有网络、训练加性侧分支。
- [ControlNet](https://arxiv.org/abs/2302.05543)，[官方代码](https://github.com/lllyasviel/ControlNet)：零初始化新增条件输出，起点保留原网络行为。
- [DINO-WM](https://arxiv.org/abs/2411.04983)，[官方代码](https://github.com/gaoyuezhou/dino_wm)：在冻结视觉特征上训练动作条件时间预测器。

这里仅借鉴可复用设计原则，没有复现整篇论文；保留原JEPA、数据和输出空间。近期/历史双调用相减是本次具体适配，不能冒称来自上述论文。Gate另复用已固定的train-only成对公共锚定损失，系数1；Motion不加该项。这是一个固定组合候选，不用于隔离每个部件的因果贡献。零初始化仅保证起点相同，不保证训练后效果。

## 固定实验

两个任务；训练种子17/29/43；每模型120轮、7680步；四条件均衡训练：recent-only、full-history、privileged B=2、random B=2。原数据seed6301、每任务512train/96validation/128普通测试/128长延迟/128背景变化pairs不变；同一pair近期RGB和动作严格相同。所有模型共用原官方冻结JEPA特征、train-only归一化、128维基底和5120维完整误差。没有新的模型输入、手写标签、未来图像或模拟器状态。h3只读h3行动前缀。

训练目标保留原完整特征MSE、2倍成对差分MSE、0.5 ranking；Gate公共锚定1。只按四条件两horizon等权validation MSE选最早最小checkpoint。参考已预训练而候选额外训练的成本完整披露，不称等训练计算量。

## 验收与停止

六个best/latest全部完成并核验来源、有限值、优化器/RNG/轮次/选模后才读取开发测试。独立CPU评价复用原始指标与统计实现，同时报告正确/错误历史、实际门状态/位置、完整特征误差及全部难例。必须通过原任务规则、对固定v3近期预测的24项检查和关键难例绝对误差的8项检查（每任务）。不删除失败种子、不降阈值、不以平均成绩覆盖失败。

两任务开发都支持后，才另行冻结新数据独立确认；此前seed9137与其它封存集保持关闭。开发通过不直接标记Phase1 GO。本阶段不添加B+1删除监督、学习selector、PushT规划或大规模真实视频新实验。
