Paper-based task benchmark (in progress)

We are establishing a task-level reference using SPACE, a published system for fixed-capacity streaming video memory. The purpose is to test whether a deployable memory controller preserves information useful for future actions, stays stable within an activity, and recovers after its memory is perturbed.

Foundation. Use official indexed Assembly101 TSM features with 219 training and 75 validation recordings, separated by participant. Predict future features at 0.5, 2, 8 and 32 seconds. Repeat the published predictor setting with three random initializations; keep recent context at 8 observations and retained memory at 16.

Matched comparisons. Freeze the predictor, a train-only predictive-state basis and utility bank, and a train-only 24-verb decoder. Compare recent-only, FIFO, Reservoir, SPACE, utility-only and state-only using identical inputs and future targets. This isolates the contribution of the memory rule.

Evaluation. Report action NLL (lower is better), mAP, LRAP and Recall@5 (higher is better), with three-run variation and participant-based paired confidence intervals. Report within-activity state drift and adaptation at activity changes. Replace 25% or 50% of memory with real earlier different-activity content, then measure state, payload and task recovery over the next 16 updates. Deleted payloads remain unavailable to the online policy.

Current evidence. Official indexed action-label alignment and full validation coverage have been checked. One training recording lacks annotations and is excluded only from supervised decoder loss. Predictor training is running on one A100; task scores and recovery results are pending. No published reference score is being presented as our reproduced result.

Reproduction scope. The release omits its dataset module and complete decoder/benchmark entry points. Our reconstructed interfaces and conventions will be disclosed. Indexed TSM alignment does not establish the original raw-video I-JEPA timing. A controlled adaptation to our memory task follows the fixed reference evaluation; it does not imply that earlier acceptance conditions have been met.
