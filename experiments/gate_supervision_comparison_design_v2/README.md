# Gate matched-supervision comparison

The two new eviction scorers in this package were trained on the existing Gate clean-future training split and evaluated on its validation split. The [current comparison and data/model description](../../docs/GATE_RETENTION_COMPARISON_LATEST.md) presents the results without the retired task-trained-score-plus-novelty method. Training used seeds 17, 29 and 43 and 1,000 updates per arm per seed; it did not retrain the predictor or encoder. No fresh independent test was run.

`PROTOCOL.md` and `protocol.json` are the original **pre-run** registration and retain their historical status text. `EXECUTION_AMENDMENT_20261029.md` records the later authorization and GPU budget. The frozen implementation and original run artifacts remain unchanged for reproducibility; in particular, `validation.py` and its historical `online.py` dependency also computed the now-retired comparator during the original run. It is omitted from the latest published comparison, not retroactively erased from raw data. Do not interpret the old preregistration's design-only wording as the current experiment status.

`core.py`, `teachers.py`, `states.py`, `fit.py`, `checkpoint_fit.py`, `artifacts.py`, `teacher_stage.py`, `asset_audit.py` and `validation.py` implement the originally executed train/validation pipeline. `run_trainval.py` and the batch scripts are original **course-HPC snapshots** with absolute paths and are not portable launchers; they require the locked upstream data, weights and transforms, which are not included in this commit. An exact replay requires independently obtaining and verifying those assets, and adapting the execution paths without changing scientific inputs. `fresh_inference.py` concerns a possible future independent evaluation and does not imply it occurred.

The 18 tests in `test_v2.py` are software fixtures, not scientific validation. The actual validation checked logical no-resurrection; offline replay holds observation prefixes, so it does not prove a B=2 physical-memory bound. See the latest report for teacher-signal, cost and manual-reference distinctions.
