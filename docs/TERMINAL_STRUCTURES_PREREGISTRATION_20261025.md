# Terminal R/D/S study: frozen execution protocol, 2026-10-25

This protocol supersedes the exploratory counts and loss choices in `GATE2_COMBINED_STUDY_DRAFT.md`. It is written before this study's visual encoding, reader training, DEV outcomes, or CONF generation. The executable configuration is `experiments/phase2/configs/terminal_structures_20261025.json`; `protocol.json` binds that configuration and the exact source hashes. Earlier Gate/Gate2 results remain development evidence from different tasks/readers.

## Question and estimands

With the same frozen visual encoder, shared reader, recent window R=4, three observed candidates and persistent K=2, compare reading weights, geometric diversity, prediction medoid, full-reference sensitivity, and learned retention. The primary endpoints are loss of semantically necessary evidence and excess expected feature MSE over the best deletion of the same three candidates. Exact choice between two redundant copies is secondary. This is one terminal decision, not an online delayed-credit experiment.

The three task families are:

- **R, redundancy:** two visually distinct copies of one axis bit and one necessary bit for the other axis. Four bit combinations produce four future classes. Duplicate axis, item order and carrier are balanced across families. Neutral, salient redundant-copy, and salient unique-evidence conditions are paired.
- **D, additive decoy:** two necessary axis bits plus an irrelevant cue. Four future classes. Neutral, salient decoy, and salient useful-evidence conditions are paired. The decoy has an observable cue-type badge; this family is not claimed to force set-conditioned selection.
- **S, relational XOR synergy:** all three candidates share the same cue vocabulary. Two matching tags identify the relevant pair; their payload XOR controls horizontal motion, while vertical motion is fixed positive. For each family and slot-payload tuple, all six nonconstant binary-tag patterns are present. Style is held fixed per slot across these patterns. There are **two**, not four, future classes. Current R/D/X context identifies the task rule, never the useful slot.

R has 12, D 12 and S 48 records per family. Candidate times are q−6,q−5,q−4; current recent frames are q−3..q. Ordinary FIFO supplies the same terminal parent, the last cue enters history at q, and no further retention occurs. q is sampled from12..18. Slots, past executed-action summaries and common context are held fixed in content-only diagnostics. Future controls are exogenous positive vectors in [.75,1.05]; they are not supplied to retention scorers.

## Reader and qualification

Use the pinned frozen I-JEPA encoder and existing `DynamicsPredictor`, hidden128/rank128/dropout0, reader seed17. TRAIN prefixes alone fit feature normalization and input PCA; TRAIN future residuals fit the output basis. These preprocessing fits count episode-prefix multiplicity (so S contributes more records); equal task weighting applies to the training loss, VAL selection, student sampling and primary reporting, not to that preprocessing. One shared reader is trained for1024 updates, at query origins only, with history sizes0,1,2,3 equally represented and equal task weight. Two factorial groups per task are sampled per update. AdamW lr.001, weight decay.0001, learning-rate halves at one-third and two-thirds. VAL is checked at step0 and every128 updates; strict earliest minimum equal-task/equal-size feature MSE selects the checkpoint. No DEV/CONF checkpoint selection.

**Loss revision before freezing:** use pure feature MSE for all history sizes. The earlier pilot's pair/rank auxiliary losses are not reused: their optimum need not be the conditional mean, which would confound the missing-information/medoid hypothesis. Full factorial batching remains. Same-XOR outcomes are never forced apart. This is not evidence that a learned reader actually reaches a conditional mean; its error geometry and missing-information outputs must be measured.

Per task and appearance condition, K2 qualification requires >=80% complete-set feature-prototype classification, >=80% content-only single-payload-flip classification, and complete-set MSE lower than each missing-evidence set by >1e−6 at matched ages/actions. R checks both redundant-copy choices. Report native-age and fixed-age conditions separately. K3 qualification requires >=80% full-set classification per condition. Prototype classes: R/D4, S2; near-equal distances report ties rather than silently granting correctness.

Report single-cue+blank arms, incomplete-set prediction-to-conditional-mean distance, strict/tie-credit class accuracy, and complete/full-set error. Balanced unobserved bits imply chance classification limits; they do not guarantee the learned prediction is a mean. No posthoc numerical “hedging” cutoff will be invented.

The same causal tensor interface is used for students. Independent forward sees one candidate and common recent context, never pooled candidate features or normalized three-item scores. Evaluator IDs, roles, tags, split, future observations, loss and future controls never enter forward.

## Predictions, interpretation and cost

Medoid with additive missing-information error vectors eA,eB chooses complete information iff 2E<eA,eB> <= min(E||eA||²,E||eB||²). Physical independent axes do not guarantee this geometry in I-JEPA features. Measure it. Ideal XOR incomplete predictions coincide, so medoid can prefer their consensus over the one correct prediction. Full-reference sensitivity is valid when the K+1 prediction is a reliable conditional mean; a wrong full prediction can reverse the ranking. Report this limitation even when its empirical score is good.

The balanced S construction forces relational processing: any scalar independent score has at most50% semantic correctness under the verified slot-local input invariance. A set student beating an independent one on this designed construction is therefore a manipulation check, not by itself a new research contribution. The stronger question is whether it beats or efficiently amortizes current attention, future-attention students and full-reference sensitivity.

If medoid or independent scores suffice on a task, report that outcome. If full-reference sensitivity suffices, the remaining opportunity is computational amortization, not superior retention. Only a frozen CONF improvement over relevant strong controls supports the proposal's empirical claim. Failure of reader qualification is a reader result, not a retention result. Do not pool qualified and unqualified tasks into a favorable headline.

Inference accounting: medoid48 forecast examples and full sensitivity64 at16 plans; report examples, batches, measured latency and hardware. They require a common reader; full sensitivity additionally requires K3 reader validity. The training/export implementation may compute a shared64-example batch, which is not a48-example latency benchmark. Separate DEV/CONF latency probes use the first parent for warmup and the next16 parents for48/64 forecasts; they include coefficient capture instrumentation and do not select parents by outcome. Students report batch1 median/p95 latency, parameters, normalization and input workspace separately. Include reference-bank bytes and all persistent memory; K+1 is the temporary eviction candidate set, not a third persistent history slot. A100 wall limit is1hour; CPU students run briefly within that allocation to avoid an extra transfer cycle. Prior0.1–0.2GPUh estimates are not promised measured cost.
