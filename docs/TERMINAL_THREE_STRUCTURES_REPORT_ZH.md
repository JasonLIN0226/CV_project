# 三种集合结构：冗余、诱饵、协同

**已完成 A100 开发集实验，发现协同任务中的 medoid 保留失败；尚未完成学习型方法或独立确认。** 作业11441为 `COMPLETED 0:0`，22分24秒，约0.373 GPUh（含编码、训练、诊断和打包的分配时间），实际超过讨论稿的0.1–0.2 GPUh估计。冻结源代码为 `4e279fc4b57bbb333cf82f2bac6cde865aa47ad9`。正式参数与停止条件见[预注册](TERMINAL_STRUCTURES_PREREGISTRATION_20261025.md)。

本次不是“三族reader全部失败”：协同S的K2检查通过，可以分析其终局保留失败；S的K3参照未通过，冗余R和诱饵D也有外观条件未通过。按预注册的全任务门槛，**未训练任何学生，未生成或查看CONF，未用新门槛重跑**。

## 已经观察到什么

D总体超过80%仍不合格：其 `salient_useful` 条件的固定时间内容检查仅60.42%，真实槽位为59.38%；不能用总体均值掩盖失败。R的 `salient_unique` 固定时间检查为53.13%，而neutral为100%；R的 `salient_redundant` 为76.04%。这些配对说明外观变化暴露了reader的问题，但没有区分是编码器缺信息、训练覆盖还是模型结构造成的。不能直接归咎于保留器。

### 协同任务支持了medoid的失败机制

下表仅为S开发诊断。K2检查通过，且四个外观条件各自通过；K3仍失败。

| 终局方法 | 丢必要证据 | 丢失率 | 平均regret |
|---|---:|---:|---:|
| FIFO | 768/1152 | 66.67% | 0.037737 |
| 固定随机终局删除 | 768/1152 | 66.67% | 0.037548 |
| diversity | 1152/1152 | 100% | 0.055940 |
| reader attention | 576/1152 | 50% | 0.026182 |
| **medoid，16个TRAIN动作平均** | **1103/1152** | **95.75%** | **0.052419** |
| 完整集合敏感度（K3参照未合格） | 672/1152 | 58.33% | 0.026245 |

Medoid丢失率的family bootstrap描述性95%区间为[94.01%,97.57%]，regret区间为[0.047906,0.056602]。这些是24个family、一个冻结reader上的开发区间，不是新seed确认或广泛任务优越性声明。平均regret按独立32计划评价库计算：先平均每一种删除的损失，再选同parent最小值；并非每个horizon分别选动作。

**新的可检验问题已经出现：两个缺信息的预测可以彼此一致，反而挤掉唯一保留完整信息的方案。** 这与先前理想XOR预检一致；但实际reader缺信息时并非精确输出条件均值，因此不能声称实测完全等于理想推导。三类失败/控制的原图与逐次删除数值见[案例图册](../results/literature_diagnosis/terminal-structures-20261025/casebook/index.html)。

距离诊断给出更直接的机制证据：1029/1152个parent中，两种缺信息预测的距离小于它们各自到完整预测的距离；medoid在这1029个parent上全部删错。两种缺信息预测之间的平均距离为0.001526，完整与缺信息预测的平均距离为0.065319。实际episode动作计划下，完整K2预测正确的1080条中，medoid仍删错1039条；此处的“读对”来自实际计划，不能偷换成独立32计划全部读对。

还要保留一个不利事实：S的期望损失oracle有159/1152次也删除必要证据。K2总体门槛通过不代表逐样本全部正确，更不保证feature MSE与语义信息完全一致。不能把全部oracle差距当作可学习的正确保留收益，也不能从full sensitivity失败就断言“完整参照原则无效”——其参照reader尚未合格。另有256条在实际计划下K2完整预测正确、K3却错误，具体暴露了加入第三项后的读取问题。

R/D全部baseline数值也已公开，但其总体reader门槛未通过，不作保留方法胜负证据。D的attention确实保住288/288份必要信息，medoid丢失38/288；R的medoid同样丢失38/288。旧Gate2的2/192开发结果没有在这里得到同任务确认：任务、外观平衡和reader均已改变。

### 接下来应做什么

1. 先用这一轮的协同失败案例讨论“预测一致不等于证据充分”，而不是继续追WR冷启动。它有合格K2 reader支持，已比旧Gate更能分开机制。
2. 另开明确的新协议检查两个reader问题：重要cue换外观后为何读错，以及同样必要pair加入无关第三项后为何变差。应先用冻结特征做廉价的bit/tag可解码与K2/K3配对诊断，再决定改训练覆盖或读取结构。该诊断不能冒充本轮已完成的因果解释。
3. 修复后重新锁定DEV/CONF及训练方案，再比较完整参照、独立与集合学生。现在没有学生结果，因此没有证明“必须集合学习”，也没有证明48–64次预测能被低成本蒸馏。

本次冻结实验到此结束；完整失败结果保留。CONF仍关闭，不为了继续出数放宽门槛。PM只同步机制联系，本轮没有新PM训练或V6.1结果。

## 这次要回答什么

固定一个预测器、三个已经观察到的候选、两个长期槽，只删除一次。先确认预测器会使用证据，再比较“读得多”“彼此不同”“删后预测一致”“相对完整集合变化小”和学习到的删除价值。每种方法的可用信息边界和保留条目预算相同；控制器参数、额外动作库及计算成本另外报告，不能声称所有方法总字节数相同。

| 结构 | 三个候选 | 正确保留 | 真正检验的机制 |
|---|---|---|---|
| 冗余 R | A、A′、B；A/A′表达同一个bit | A+B 或 A′+B | 外观不同、读取权重大，不一定有额外价值 |
| 诱饵 D | A、B、D；D不影响未来 | A+B | 显眼的条目是否挤掉有用证据；配套“显眼者有用”的控制 |
| 协同 S | 三个带tag的cue，两个tag相同 | 同tag的两条，二者payload做XOR | 两个缺信息预测互相一致，可能压过唯一完整的预测 |

R/D有四种真实未来；S只有两种。三个任务都从正常FIFO过程得到q−6、q−5、q−4三个候选，最后一条恰好在query离开recent。之后不再继续淘汰，因此不会把后续策略的表现混进这次决定。

## 对讨论稿的三个必要修正

**诱饵不保证medoid成功。** 设保留AB的预测为p，缺A/缺B的误差向量为eA/eB。对同一个动作库和两个horizon平均后，medoid选完整集合的条件是 `2 E〈eA,eB〉 <= min(E||eA||², E||eB||²)`。正交误差满足它；物理上两个独立方向，不代表视觉特征空间中的误差正交。必须测实际预测几何。

**XOR不自动要求集合条件打分。** 若诱饵总有固定外观或位置，逐条目打分照样可以删掉它。本实验把三条cue的tag做成`(u,u,v)`，让同tag pair有用；每组固定槽位内容/外观完整交叉六种tag排列。逐项打分不知道自己的tag在集合中出现几次。720种位置/tag分数排序的精确枚举证明：在这个输入约束下最多正确3/6。这个上界是设计性质，不是新方法贡献，也不适用于已经看过集合统计的模型。

**完整集合敏感度依赖reader是否可信。** 它比较 `f(ABC)` 和 `f(删i)`，能解决理想XOR的多数投票问题；但完整预测本身错了时，最“自洽”的删法也可能错。因此同一reader训练历史大小0–3，分别检查K2和K3。预测一致不等于对真实未来有用。

## 如何避免重复之前的评测问题

- 正确内容、翻转内容、单证据和缺证据条件使用相同时间/动作比较；完整集合预测单独检查。
- 新reader统一纯特征MSE；旧排序损失不保证条件均值，会干扰“缺信息时对冲”的解释。修改在编码和训练前写入协议，旧pilot结果不改。
- 选择器只看当前及过去，预测型规则使用固定的16个TRAIN参考动作；不读取实际未执行计划。评价采用另一个32计划库，先平均损失再选择一次oracle删除。
- 独立学生和集合学生共用输入及近乎相同参数量，分别交叉删除代价、未来attention和打乱标签。每个学生用自己的VAL标签CE选checkpoint，不能暗中给attention学生用真实cost选模型。
- 未来attention来自冻结reader在真实未来query上的读取分数；reader只在query训练，所以这个teacher存在分布偏移，必须保留这一限制。
- 主终点是必要证据丢失率和regret；不要求精确复现两个冗余副本之间的每一个MSE最优选择。按基础family计算区间，不能把siblings或训练seed当独立样本。

## 什么结果才值得继续

若medoid或独立学生已足够，报告这个结果；若完整集合敏感度解决质量问题，下一步主要是把48–64次预测蒸馏成便宜的选择器。只有在reader合格、强控制充分、独立确认仍有收益时，才讨论proposal的核心经验主张。人为构造的关系任务让集合模型胜过独立模型，本身不能证明新颖性。

若某任务reader资格失败，该任务尚不能用这个reader支持整体保留方法比较；其他已通过任务仍可单独作开发诊断。保留完整失败数据，不训练学生、不打开确认集、不为了得到通过而改门槛。当前实验也不证明在线延迟信用、PushT规划或自然视频上的效果。

## 阅读时关注的对应关系

- [CAOTE](https://arxiv.org/html/2504.14051v6)：观察完整注意力输出与删除后的偏差。它说明完整参照原则已有先例；不能把世界模型版本包装成全新原则。
- [ReST-KV](https://arxiv.org/html/2605.08840v1)：同样围绕输出重构误差，但具体对象是KV缓存与注意力输出。本实验使用世界模型的未来特征预测，二者不是同一算法。
- [Partial information decomposition: redundancy as information bottleneck](https://arxiv.org/html/2405.07665v2)：借其冗余、独有、协同的区分组织案例；本实验不估计PID量，也未证明这是PID首次用于记忆。

PM只同步研究联系：世界模型能否帮助决定保留、修正或遗忘。该仓库本轮没有新实验，V6.1 S0–S2、预算和FINAL规则保持原样。
