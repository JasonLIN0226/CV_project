# Motion v2.1 保留对比结论与 CPU 事后诊断

**事后探索性分析，未预登记。** 本文的新增诊断、跨任务解释和收尾结论均为事后分析；引用的第2步、第3/4步和terminal structures CONF结果仍保留各自原来的预登记身份与范围。日期：2026-11-09（纽约）。

**Motion v2.1的保留对比到此结束，不打开Motion确认集。** 第2步证明冻结预测器在特权正确帧条件下可以利用方向；第3/4步没有产生通过validation选择的已训练删除代价候选，且通用attention已达到语义成功率上限。此次仅读取已导出的train/validation标签及既有曲线/摘要，执行CPU统计；新增A100用时0秒，累计仍为5886秒，剩余 **8514 A100秒未使用**。

## 1. 已有证据与本次解释的范围

[第2步报告](MOTION_V2_3_1_RESUBMISSION_REPORT_ZH.md)的普通间隔h3/h6正确帧b position MSE为0.006052 / 0.006860；无方向下界B为0.010503 / 0.014639，B−b的配对95%下界为 **0.002709 / 0.006024**，均>0。d−b与c−b亦通过。这说明模型在给定正确两帧时能利用方向，不能由此推出在线保留器一定能找到它们。后来的long-gap validation也通过方向检查（B−b下界0.015175 / 0.013289）。

[第3/4步报告](MOTION_V2_STEP3_4_RECOVERY1_REPORT_ZH.md)中，attention baseline和集合future-attention学生在普通/long gap的成功率均为100%。54个学生都完成1000次更新，但四种删除代价及其shuffle对照的48个臂全选step0；这是**未训练初始化**，不能称为“标签训练后的学生”。主要集合候选成功率仅5.903% / 1.563%，联合判据未通过。集合/独立差值区间包含0；本任务不能区分集合条件作用，也不证明两者等价。

这里的“删除代价标签噪声主导”是相对保住方向证据这一语义目标的解释：标签排序不稳定、很多父集无信息竞争，类型参照对四种代价目标的泛化收益很小。它不是已估计出的噪声方差分解，也不是唯一原因的因果证明。隐藏类型参照仅是用户要求的特权分组均值分析，不进入原预测器或可部署保留学生的输入。

## 2. 诊断口径与可复现输入

输入固定为作业17925导出的 `labels/train` 与 `labels/validation`：16384 / 3072条父集，保留原行为策略、clock、siblings和重复父集权重；没有按结果去重或筛选。读取原manifest的split/scene_index，以冻结的 `envs_v2.scene` 重建608个train/validation scene的隐藏时间结构，并核对seed、query、gap、长度与pair ID。没有调用episode/render，没有打开RGB/特征/位置episode数组、checkpoint或Motion确认/test数据。

每帧分成O（遮挡）、S（旧段可见）、P（新段可见且非end）、E（end可见）；P/E都计作新段。父集组成只记四类计数，时间名次按实际timestamp从旧到新为0/1/2。标签及隐藏注释只用于事后解释，不回写任何模型输入。

四种代价取保存的3预测器×2 horizon平均值。目标概率严格沿用训练公式：`softmax(-(cost-parent_mean)/train_RMS)`，最后转FP32；**future_attention也使用负号，表示删除低attention项**。五个scale均与保存的训练scale逐值相同；5项合成算术测试通过，其中目标函数与冻结训练源码抽取出的纯NumPy函数逐值一致。只读取保存的训练曲线和在线摘要，不重算预测、损失或bootstrap。

隐藏类型参照的候选键为“类型＋池内时间名次＋O/S/P/E组成”，train上累加目标概率取键均值，再将每个validation父集的三个查表值归一化。75个train键覆盖全部validation候选，没有未见键。该参照的查表均值仅由train拟合。

### 与用户提供的Claude参考值核对

15项给定数值中，**13项在参考精度下舍入一致，2项不一致**；没有为了贴合参考值改变定义或覆盖首次诊断输出。

1. train的use_time_position保对率是 **1015/1599=0.6347717323**，直接保留两位小数为0.63，参考为0.64。差0.0052283（0.5228个百分点），略超过两位小数的舍入范围。若先舍入三位0.635再舍入两位可得到0.64，但参考是否用了双重舍入未知；不擅自归因为数值误差或改argmin。
2. 实际训练删除目标下的future_attention CE是 **0.9589621702**，参考为0.726。实际目标熵 **0.8689342889** 已大于0.726，故0.726不可能是同一目标、同一行权重下的归一化概率预测的CE（FP32舍入量远不足以解释该差异）。原训练源码的负号与保存的RMS已经核对；参考脚本未提供，差异来源仍未解决。

为核查方向混淆，另做一次明确标记的事后敏感性算术：仅把future-attention改成正号的“保留”目标，会得到CE0.840172188、熵0.706366226，仍不匹配0.726。这个目标**不是实际学生训练目标**，没有替代正式诊断，也未据此修改模型或重训；结果单独保存在reference_reconciliation.json。

## 6. 保存的训练曲线为何选择step0

对24个未打乱删除代价臂（四标签×两架构×三seed），24/24的最后100步平均train CE低于最初100步；24/24在step100的validation CE高于step0，此后每个检查点也都高于step0，故原选点规则必然选择初始化。逐步训练loss是不同minibatch的值，不能称作全train CE的严格下降序列。

以100步分块后，只有16/24臂的train块均值严格递减；validation在step100之后严格逐点递增的只有2/24。因此参考中的“持续下降/从100起上升”可作为总体趋势，但严格逐点单调版本不成立。30个未打乱臂（含6个future-attention）的完整块均值及11次validation值保存在diagnosis.json；原54臂全曲线和checkpoint保持不变。

结合低信息父集占比、标签与语义的一致率下降、类型参照泛化收益小，这些曲线支持当前训练方案在拟合不稳定的teacher细节，未学到更可靠保留规则的解释。选中step0不等于“训练没执行”，也不能单独定位到优化器、模型容量或标签定义中的唯一原因。

## 8. 与terminal structures S协同任务的适用边界对照

引用的是[既有terminal structures CONF报告第8节](QUALIFIED_READER_RETENTION_DEV_ZH.md)，本次没有重新打开其数据或重算结果。48个新family的一次性CONF中，两个冻结合格reader的S任务集合删除代价学生的必要证据丢失率为 **4.59% / 0.65%**，显著低于attention的70.27% / 55.12%和同架构future-attention的67.38% / 56.29%；原三条登记主张均通过。该证据限于终局一次K=2删除、指定合成S结构及固定reader/学生，不是一般在线或自然视频结论。

| 条件 | Terminal structures S（已有CONF） | Motion v2.1（validation＋本次事后解释） |
| --- | --- | --- |
| 信息竞争 | 每个三候选父集都有必须保留的协同对，删错会丢必要证据 | 约2/3父集无新段帧；只有约1/3处于1–2张新段与非新段竞争 |
| 单项与集合价值 | 两条payload依赖集合tag关系共同决定目标，逐项权重难表达联合保留价值 | 单张帧对方向的信息弱，逐帧识别可见线索已能支撑“最近两张可见帧”规则 |
| attention现状 | 读取权重未能正确反映S的保留价值 | attention已追踪所需线索，普通/long gap成功率均100% |
| 删除代价监督 | 在该S设置上确认能训练出保留必要证据的集合学生 | 当前teacher/状态分布中的监督不稳定；候选全选初始化，未获有效已训练候选 |
| 删除时点 | 一次终局删除，父集的价值差直接对应同一目标 | 很多删法不改变当前语义证据状态，后续attention还会使不同删法合流 |
| 可支持的结论 | 删除代价在该协同竞争条件下确认有效 | 该配置未建立删除代价学生收益，且强baseline已无成功率提升空间 |

**这给出方法的适用边界，而不是方法成功或失败的一般结论。** 当父集普遍存在稳定的互补信息竞争、attention读取权重不足以表达保留价值、teacher的删除损失与语义需求足够一致时，删除监督加集合条件具有被验证的适用实例。Motion v2.1不满足同样的经验条件；其结果不能否定S的确认，也不能用S的成功替Motion补上未通过的训练/validation门槛。
