# 延迟删除信用：2026-10-24 可行性试验

这轮把“标签是否错了”“reader 能否使用证据”“学生能否学到保留收益”分开检验。已完成原训练数据的标签审计、固定 continuation 的 use-time 标签与学生试验，以及 A100 上的 16/64/512 对 reader 比较。也已完成 512 对训练、36,099 个删除决策的学生试验。结果是：use-time 修正可以学到，但仍未胜过 attention/diversity 强基线。

模型、保存预测、核验目标与执行证据可从[实验预发布包](https://github.com/JasonLIN0226/CV_project/releases/tag/gate-use-time-reader-pilot-20261024)下载；原始 1,282 个 parent 的精确输入/标签也已导出到标签审计目录。大规模原始逐帧缓存仍保留在 HPC，完整在线复跑的依赖范围另见 reader 报告。

## 目前已经检验的三个层次

| 层次 | 实际结果 | 可以说什么 |
|---|---|---|

| 改在使用时刻评价 | 同一批 parent 统一 attention 续跑，use-time 的最优集合没有一个包含删 cue 的动作 | 指定 continuation 下的反事实排序得到修正；尚非在线泛化收益 |
| 原 16 对训练的学生 | use-time 在训练 32/32 保 cue，但已查看开发集仅 74/192，MSE 0.125385；attention 192/192、0.110337 | 这个固定 ridge 配置没有泛化成功，不能宣布方法成立 |

## A100 上确认了什么

作业 **11026** 在 **NVIDIA A100-SXM4-40GB** 上执行，Slurm 最终状态 `COMPLETED`、退出码 `0:0`，单 GPU 分配时间 **539 秒**。Torch 设备 UUID 与 `nvidia-smi` 一致。编码 8,640 张去重图像后，三个 reader 各训练 512 次更新。

在同一批 96 条 episode / 48 对新场景中：

| Reader 训练场景对 | 保正确 cue 的 MSE | 正确 cue 比匹配的错误 cue 更差 | 至少一个 horizon 的特征方向错误 |
|---|---:|---:|---:|
| 16 | 0.104284 | 19/96 | 33/96 |
| 64 | 0.073858 | 2/96 | 10/96 |
| 512 | 0.057564 | 2/96 | 4/96 |

512 对 reader 的剩余两条“正确 cue 更差”来自同一对场景，不能当成两个独立发现。这里的方向是 sibling future feature 对比轴上的符号，不是解码后小球轨道准确率。旧图册中的具体 case 没有逐一重放，不能说每个旧 case 都已被修复。

独立 NumPy 审计直接使用下载的 1,920 条保存预测和 96 条目标，重算逐条误差与 80 个汇总值，全部通过；最大 MSE 算术差异为 1.11e−16。该检查验证数值与文件绑定，不替代任务语义验证。三模型同初始化、同最大更新预算，但 validation 选择的步骤分别为 128/448/448；只有一个训练 seed。因此它是固定训练与选择流程下的覆盖比较，不能把全部改善严格归因于单独的数据量变量。

## 扩样学生的完整比较

冻结上面的 512 对 reader，四个学生采用同样的 903 维因果输入、TRAIN 支持掩码、ridge λ=1 和 K=2。训练集 512 对 / 1,024 条 episode，评价集 48 对 / 96 条 episode；ID、长间隔和干扰移位各 16 对。此评价集已在 reader 分析时查看，因此这仍是开发 pilot。

| 策略 | cue 留到 query | 未来 feature MSE ↓ |
|---|---:|---:|
| 短期 local-cost 学生 | 0/96 | 0.113421 |
| use-time cost 学生 | 96/96 | 0.058482 |
| 打乱 use-time 标签的学生 | 27/96 | 0.096232 |
| future-attention 学生 | 96/96 | 0.058471 |
| reader attention 保留 | 96/96 | 0.058295 |
| visual diversity | 96/96 | **0.056376** |

use-time 相对 local-cost 的配对 MSE 差为 −0.054939（95% bootstrap CI [−0.059738, −0.048445]），相对打乱标签为 −0.037749 [−0.046107, −0.029094]。但相对 attention 为 +0.000187 [−0.000582, +0.001209]，没有显著优势；相对 diversity 为 +0.002106 [+0.000694, +0.004180]，反而更差。这些 CI 是本 pilot 的场景对重采样，未经多重比较校正，不是新确认集结论。

逐轨迹还发现：local-cost 在全部 1,708 次 overflow 都拒绝新条目，最终 96/96 条轨迹固定为最早的 `[0,1]`；cue 从未进入长期槽，恰在离开最近 4 帧窗口时完全消失。这是入口拒绝和槽位固化，不能描述成已保存 cue 后的随机晚期淘汰。

**可学习性得到一次正面验证，超过强基线的研究假说尚未得到支持。** 扩样前后同时改变了 reader 和 scorer 的训练覆盖，不能把两轮学生结果的差异全部归因于 reader。原 16 对负结果仍保留，不因新结果覆盖。

详细协议、逐样本结果、不可逆轨迹及独立核验见 [GATE_SCALED_USE_TIME_PROBE.md](GATE_SCALED_USE_TIME_PROBE.md)。CPU worker 11065 `COMPLETED / 0:0`，分配 786 秒，实验主体 759.7 秒；复用了完成的 A100 reader 和特征，没有增加 GPU 训练。

## 为什么不能直接宣称发现了新的延迟信用方法

原开发 reader 只在 `query` 时刻训练，local-cost 却在每个 overflow 时刻调用它。use-time 同时把目标移到证据发挥作用之后，也把 reader 的评价起点移回训练分布。这两种变化没有被本轮隔离。虽然 use-time 学生已改善，仍需要一个多起点训练的 reader 对照，判断收益是否只是修正了 teacher 的使用分布。

“延迟的任务反馈学习保留什么”已有先例：[LEMN](https://arxiv.org/html/1812.04227) 使用后续问答奖励学习有界记忆替换；[KVP](https://arxiv.org/html/2602.10238) 以未来 attention 构造强化学习奖励；[TVT](https://arxiv.org/html/1810.06721) 把后期关联到记忆的价值传回较早动作。这些工作与逐条目反事实删除目标不完全相同，但足以排除“延迟信用本身是新意”的说法。本轮也没有比较估计方差，不能把“反事实所以低方差”写成结果。

补查原文后，还有更直接的先例，建议先读前两篇：

| 论文与版本 | 与本试验的重叠及区别 |
|---|---|
| [VitaBench / VitaMem，2026-10-10 v1，§5、附录D](https://arxiv.org/html/2610.14731v1#S5) | 已用同状态动作分支、相同未来流及 continuation 生成长时距标签，再训练只看过去的学生，并讨论后续策略的影响。其生命周期动作和指定算子效用不同于固定K帧的视觉预测损失，但高层方案已重叠。 |
| [MGPO，2026-09-29 v1，§2](https://arxiv.org/html/2609.37930v1#S2) | 以文本记忆改写前后对当前及未来任务的增量效用训练writer；不是逐帧K+1删除后继续淘汰，但已覆盖延迟的反事实记忆信用。 |
| [OSL-MR，2026-06-29 v6，§3](https://arxiv.org/html/2606.10616v6#S3) | 已研究预算、延迟成本和离线证据监督／在线可观察输入隔离；其证据成员标签与可付费重新获取不同于本试验。 |

因此，**作为课程 proposal 内的受控适配可以继续，作为独立新方法的创新性尚未成立**。固定K或改成视觉任务本身不构成创新证明；后续必须具体说明哪个未解决的失败仍存在、为什么已有方法不能解决。上述差异只是待检验的研究线索。

与原 proposal 的对应也很明确：归档文本 p013 允许较长训练时距并承认超出时距后的泛化问题，p014 要求同结构 future-attention 对照，p024 要做时距与监督消融；p031 的目标本来就包括解释删除代价监督何时有效、何时失败。因此这轮能服务课程目标。use-time continuation 是这次明确披露的评价变体，并非声称 proposal 已规定这一具体算法；它也不替代尚未完成的 Motion 历史验证或 PushT planning。

## 下一步的判断标准

上述比较已经完成。最先需要补的是 **teacher 起点分布 × 标签时距** 的隔离：在相同场景与训练预算下，让 reader 同时学 query 和 overflow 起点，再比较 local 与 use-time 标签。先确认它在使用前能正确预测静止、在使用后能利用 cue；否则 local-cost 的失败仍混有 teacher 分布外误差。

此后再考虑“显眼但无用”的诱饵竞争任务：先验证强基线确有稳定失败、正确证据在过去可识别且 reader 会用，再在未查看的新 seed 上比较相同结构学生。当前 Gate 的 cue 保留缺口已被强基线解决（本批均 96/96），但仍有 reader 残余错误；继续堆相同 Gate case 不能证明 use-time 超越强基线。

若只能修复早丢，仍可作为 proposal 中监督目标的受控消融。只有在强基线也遇到稳定、可由过去区分的失败，并且价值监督学生在新 seed 上获得收益，才值得进入方法主线。诱饵任务需要让过去信息足以判别真线索，不能依靠隐藏随机角色制造不可学习的 oracle 优势；也不能预先保证 attention 或 diversity 必然失败。

本轮没有实现 TD。条目间的互补、未来替换策略和终止条件尚未写成完整状态与目标，直接使用“当步代价 + γ × 下一步存活价值”可能把不同反事实混在一起或重复计分。PM 仓库只更新证据连接，不把本次 CV feature MSE 当作 PM 的新实验结果。
