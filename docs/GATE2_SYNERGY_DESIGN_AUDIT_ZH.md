# 三结构终局实验：先把协同、集合选择和reader参照分开

2026-10-25。**本轮完成了精确符号预检和两个预测打分函数的实现，没有训练新视觉reader、没有新A100作业，也没有打开确认集。** XOR确实能使理想medoid选择错误，但XOR本身不能证明独立保留器不够用；需要让有效配对由已观察集合中的关系决定。修订后的[三任务草案](GATE2_COMBINED_STUDY_DRAFT.md)据此分别检验两种机制，仍未冻结为可执行的视觉实验协议。

## 1. 诱饵为什么可能成功：须写明特征几何

令删D的完整预测为p，删A、删B的预测为p+e_A、p+e_B。内积使用与实验相同的horizon/feature均值，并对固定参考动作库平均。写a=E||e_A||²、b=E||e_B||²、c=E〈e_A,e_B〉，则三个平方MSE-medoid分数为：

| 删除 | 距离和 |
|---|---:|
| D | a+b |
| A | 2a+b−2c |
| B | a+2b−2c |

因此删D是最优动作当且仅当`2c≤min(a,b)`，严格不等时唯一。用户给出的加性推导是c=0的情形，成立；但物理x/y轴独立不等于I-JEPA预测误差正交。对冲只是预测均值的性质，还需要检验均值之间的特征几何。下一轮保存a/b/c，先核对条件是否成立，再解释medoid成败。

精确有理数程序检查81组二维误差向量，与这个条件完全一致；还保留误差同向时medoid失败的几何反例。该反例没有声称来自已训练视觉reader。不能再把“只有一个删除完整”直接当作诱饵能击败medoid的理由。

## 2. XOR反例成立，但只回答其中一个问题

若A、B是独立公平bit，未来由A XOR B决定，缺任意一个bit时条件均值都是1/2。设完整预测为u、两个缺信息预测都为m，且δ=||u−m||²>0：删D得2δ，删A或B各得δ，medoid必删必要项。这个失败来自**两个相同的不完整预测占据共识**，不是平局实现错误。

在解析的正确条件均值reader上，程序穷举bit和候选顺序：

| 符号任务 | Medoid保住必要证据 | 完整集合敏感度保住必要证据 |
|---|---:|---:|
| 冗余 | 24/24 | 24/24 |
| 正交加性诱饵 | 48/48 | 48/48 |
| XOR，角色可见 | 0/48 | 48/48 |

这是有限数学例子的枚举，**不是新视觉场景上的准确率**。真实reader的两个缺信息预测未必相等，必须实测其条件均值误差、时间偏差和相互距离；不能为获得medoid失败而调reader。

同时，在“角色可见”的XOR中，一个逐项规则给D低分、A/B高分，也能48/48保住证据。故“XOR→独立scorer必败”的表格需要改：XOR要求联合**预测**，不自动要求联合**决定保留谁**。

## 3. 可观察的关系配对：让集合条件检验有明确含义

三项都携带可见tag与payload bit。六种tag排列为001、010、100、011、101、110；同tag的两项是有效配对，未来为它们payload的XOR，singleton为D。角色由过去观察完全确定，不是模拟器偷偷指定的重要性。

每个基础family固定背景、三个时间槽、动作、规则提示和逐槽其他外观；完整交叉六tag排列与八种逐槽payload，共48个不同的结构case。显眼程度可以跨family变化，但同一family不能按“这次谁是D”改变某槽的外观。当前/recent只能公开规则，不能泄漏配对tag或某槽的角色。

这个设计有一个可审计的上界。固定三个槽位payload及共同上下文后，独立标量scorer只能给出六个值`s(slot,tag)`。要求它在每个排列删除singleton，会形成六个互相冲突的排序要求。枚举全部6!=720种全序：96种排序正确1/6，528种正确2/6，96种正确3/6，**最高为50%**。固定的最早槽位平局规则可细化为全序，所以不遗漏平局策略。

这个界允许独立scorer使用年龄、位置、自身payload和不泄漏tag排列的公共context；不覆盖跨候选attention、集合统计、记住其他tag的控制器状态，或按真实角色赋予外观的生成器。后者一旦出现，理论前提失效，而不是网络突破了上界。简单的集合规则“删只出现一次的tag”可以全部选对，证明存在从过去信息可实现的正确策略；它不证明神经学生已经学会，更不提供方法新颖性。

程序还枚举四种局部(tag,bit)类型的全部75种弱序，最优保留率同样50%，全平分为1/3。这说明不能从单项角色概率相同直接推出任何独立排序都只能随机。关系部分的符号输出保留了96个带原始角色顺序的枚举项，它们是48个可见结构各重复两次；不是96个独立场景。视觉协议将只生成48个不同结构。

**两种归因分开：** 同tag关系使独立排序不够用；XOR使两个缺信息预测相同，从而误导medoid。角色可见XOR的成功对照保留在符号预检中，防止混淆。

## 4. 完整集合敏感度加入，但不能默认参照正确

使用同一固定TRAIN动作库，计算完整K+1集合和三个K子集预测，删掉

`argmin_i mean_a MSE(f(C,a), f(C\{i},a))`。

所有方法在淘汰瞬间本来都能看到三候选，决策后仍只保留K=2；它额外使用的是一次完整三项reader读取与计算，并未多出一个持久历史槽。16计划下，medoid有48个预测样本，完整参照有64个；同时评价可复用其中48个子集预测，但独立部署成本要各自报告，K=3那次的FLOPs/工作区也可能更大。

这一方法有条件性的MSE解释。给定完整已观察集合C和计划a，若完整预测μ等于真实条件均值E[Y|C,a]，则对任何由C、a决定的子集预测p_i：

\[
E[\|Y-p_i\|^2-\|Y-\mu\|^2\mid C,a]
=\|p_i-\mu\|^2.
\]

展开平方后交叉项因条件均值为零而消失；不需要额外假定p_i也是最优预测。**这个条件并未在我们的视觉reader上得到证明。** 若完整预测偏了，敏感度可能忠实地保留错误。符号预检保存了一个反例：真实目标0，完整参照错误地输出1/2，删D预测0、删A/B预测1/2；敏感度选择错误删除。

下一轮所有方法共用一个训练历史大小覆盖0–3的冻结reader。分别检查K=2完整语义子集、K=3完整候选、无关D/副本扰动和只换payload的反事实响应。旧K=2 checkpoint不直接当作合格的K=3参照；不在旧开发结果上临时调用它并宣称比较成立。

## 5. 评价接口和后续实验

纯XOR只有两种未来：00/11相同，01/10相同。保留四输入组合，但S族使用两种去重目标、50%机会水平及缺信息预测到真实条件均值的距离；不得沿用四目标必须不同的断言、四原型分类或将同XOR样本当负例的loss。R/D四未来与S两未来指标分别报告，特征MSE也不跨符号目标维度合并。

三任务的主终点仍为必要证据丢失率和同动作库的regret。先对每种删除的动作损失取平均，再选一个oracle删除；不使用每个动作分别取最小再平均的额外特权oracle。训练/评价动作库、样本量、参数和确认seed须在新数据前冻结。当前[协议](GATE2_COMBINED_STUDY_DRAFT.md)仍有明确待填的视觉编码和reader容差，不能称为已预注册运行。0.1–0.2GPUh的估计需先profile，旧pilot耗时不等于三族新研究耗时。

该构造本来就要求关系处理，所以“集合学生胜过独立学生”主要验证实现是否学到了该关系，不自动成为新的方法贡献。仍须与future-attention标签和完整集合敏感度比较。若敏感度已解决质量问题，学生的候选价值是用更低计算成本近似它；只有真实测得质量/成本收益才作该主张。符号tag-count规则用于证明过去信息足够，不能在视觉主表里直接读取模拟器tag元数据并冒充同输入baseline。

现已实现[prediction_retention.py](../experiments/phase2/prediction_retention.py)中的两个纯预测打分函数，216个符号枚举项的选择和分数均与精确有理数实现一致，共享动作复制检查通过；代码不接收真实目标或语义标签，但这不代替未来runner的输入隔离检查。冻结的旧Gate2代码、预测和结果均未修改。

完整证据：[精确预检源码](../experiments/phase2/audit_terminal_synergy_preflight.py)、[汇总](../results/literature_diagnosis/terminal-synergy-preflight-20261025/summary.json)、[数值实现检查](../results/literature_diagnosis/terminal-synergy-preflight-20261025/implementation_checks.json)。运行`python experiments/phase2/audit_terminal_synergy_preflight.py --help`查看复算接口；仅需Python标准库，不调用reader或GPU。

## 6. 文献与原型代理澄清

[PID论文](https://arxiv.org/html/2405.07665v2)提供冗余、独有与协同的组织框架；这篇文章的具体方法主要处理redundancy bottleneck，不等于已给我们的视觉记忆定义或估计完整PID。本轮用可控生成规则检验机制，不以“首次用于记忆”作主张。

[CAOTE](https://arxiv.org/html/2504.14051v6)和[ReST-KV](https://arxiv.org/html/2605.08840v1)都将删除前的attention输出作为参照，控制KV删除造成的输出误差。完整集合敏感度与这一原则更接近，但本轮使用多horizon世界模型预测及参考动作平均；仍是机制适配，不是原论文系统复现。

评审已澄清旧3/192代理使用开平方后的欧氏距离，本地12/192代理使用MSE距离坐标，两者定义不同。保留原始两种定义的记录，不再追3这个数字。完整预测向量及因果TRAIN动作库的2/192开发结果不受这项澄清影响。
